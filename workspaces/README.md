# 環境

VSCodeで開発環境コンテナを使う前提。
コンテナで開くと、webコンテナにアタッチする。

## devcontainer.json

ワークスペースの設定、マウントディレクトリを記述。
ワークスペースのマウントもしており docker-compose.yml には記述していない。
コンテナ環境内で動かすためにコンテナ内で `ng new my-app` を実行してアプリケーションを作成する。

## Angular app のコンテナ内起動

通常の起動ではlocalhostで動かしてしまい、コンテナ外からアクセスできなくなってしまう。
以下のコマンドで実行しホストマシンからアクセスできるようにする。

```
ng serve --host 0.0.0.0 --open
```

開いたブラウザをそのまま、コードの変更を反映させたい場合はポーリングして変更確認する。

```
ng serve --host 0.0.0.0 --poll --open
```
